# FootMonde et CinéFR

- `index.html` : FootMonde (où regarder le football, diffuseurs officiels)
- `cinefr/index.html` : CinéFR (films et séries en français, plateformes légales)

## Mise en ligne sur GitHub Pages
1. Crée un dépôt public sur GitHub.
2. Envoie tous les fichiers à la racine du dépôt.
3. Settings > Pages > Source : branche `main`, dossier `/ (root)`.
4. Le site sera sur `https://TON-PSEUDO.github.io/NOM-DU-DEPOT/` (CinéFR sur `/cinefr/`).
